# AppTimer（LSPosed 版）0.0.002

本版本在「更多」中新增「主题设置」，并扩展配置备份格式。既有计划、日志、权限与模块作用域不受影响。

## 本版本变更

- **主题设置入口**：「更多」首页新增「主题设置」，位于「配置说明」与「关于本软件」之间。
- **主题模式**：可选择「跟随系统 / 浅色 / 深色」；默认仍为跟随系统，不主动改变原有界面深浅。
- **按钮配色**：提供青蓝、松绿、琥珀、绯红、靛蓝、紫藤、石墨、暖沙八组预设色，并支持 RGB 自定义。按钮文字色按实际合成底色自动选择黑或白，不再固定白字。
- **按时段切换配色**：可分别设定日间色、夜间色、日间开始时刻与夜间开始时刻；跨午夜时段可用，界面每分钟自动刷新。
- **背景**：提供晨雾、极光、暮色、山林、石墨五组内置渐变，以及系统文件选择器中的自选图片。自选图片仅保存内容 URI，不复制文件、不申请存储权限。
- **透明度**：背景透明度、内容遮罩与按钮不透明度均可调；按钮不透明度下限为 20%，背景遮罩默认 18%，用于保障正文可读。
- **界面预览**：主题页顶部提供按钮、选中标签、卡片与背景的即时预览；保存前不写入配置，返回即放弃本次调整。
- **恢复默认**：一键回到跟随系统、青蓝按钮、无背景。
- **配置备份**：导出 JSON 新增 `theme` 对象；导入时旧备份没有该对象则保持本机主题。自选图片地址不写入备份，导入时统一退回无背景。
- **版本号**：`versionCode 2` / `versionName 0.0.002`。

## 安装步骤

1. 设备已取得 root，并已安装 LSPosed（Zygisk 或 Riru 均可）。请将本模块作用域设为「系统界面」，随后重启系统界面。
2. 安装 `apptimer-lsposed-v0.0.002.apk`。同签名版本可直接覆盖升级；签名不同的旧包须先卸载。
3. 打开应用，进入「更多 → 主题设置」，按需调整并保存。
4. 若曾在旧版选择自选背景图片，升级后请重新选择一次；旧图片授权在清空应用数据或换机后不再有效。

## 使用前须知

- 锁屏密码仍以**明文**存储于本机，导出的备份亦然，请勿转交他人。
- 自选背景图片由系统文件选择器授予持久读取权限；若文件被移动、删除或权限被回收，背景将不再显示，需重新选择。
- 主题仅影响本应用界面，不改变计划执行、解锁、锁屏与权限逻辑。
- 本版本主要在 Xiaomi 15（澎湃 / Android 15 / LSPosed 2.1.0）验证，其他机型请自行测试。
- **使用本软件所产生的一切后果由使用者自行承担，作者不提供任何形式的担保。**
