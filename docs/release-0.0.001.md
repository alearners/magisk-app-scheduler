本版本为仓库重置后的首个发布版本。此前的提交、标签与发布均已删除，自此重新开始。

## 本版本变更

- **版本号规范化**：显示版本统一为 `0.0.001`，构建号 1；钩子版本常量同步为 1，不再附加构建次数等后缀。
- **运行环境信息完善**：「概览」与「关于本软件」的运行环境一行现显示已安装的 LSPosed 版本，例如 `已取得 root（Magisk / KernelSU），LSPosed 2.1.0`；未检测到管理器时如实显示「未检测到」。
- **应用选择页调整**：页面标题为「应用选择」，确认按钮显示当前选择数量，如「已选中 1 个应用」；计划总开关状态改用「已启用 / 已停用」表述。
- **配置页精简**：移除导入导出指引与日志大小设置，配置页仅保留定时开关、计划列表、全局设置与系统权限提示。
- **日志页整合**：日志大小上限调整移至日志页，通过「设定」按钮打开；筛选顺序调整为「全部 / 运行 / 错误 / 调试 / 设定」。
- **文案统一重写**：应用内使用说明、启动方式、配置说明、关于、概览核验说明、各类提示与对话框，以及仓库根 README、LSPosed 版 README、开发说明与发布说明，均按正式书面语统一重写，重点说明「执行何种操作、可能产生何种影响、应当如何处理」。
- **界面截图重录**：概览、日志、配置、更多等页面按新文案重新渲染。

## 安装步骤

1. 设备已取得 root，并已安装 LSPosed（Zygisk 或 Riru 均可）。请将本模块**作用域设为「系统界面」**，随后重启系统界面。
2. 安装 `apptimer-lsposed-v0.0.001.apk`。同签名版本可直接覆盖升级；签名不同的旧包须先卸载。
3. 打开应用，底部依次为「概览 / 日志 / 配置 / 更多」。请先在「概览」勾选使用说明，再逐项处理标红项目。
4. 在「配置」页新建计划：选择应用、设定时间；如需自动锁屏，请开启开关并填写秒数。
