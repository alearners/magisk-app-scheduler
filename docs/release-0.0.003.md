# AppTimer（LSPosed 版）0.0.003

本版本在 0.0.002 的界面修复基础上，将全局提示条升级为可自由拖动，并在「更多」中新增「通知位置」设置页。既有计划、主题、日志、权限与解锁逻辑均不受影响。

## 本版本变更

- **通知位置入口**：「更多」首页新增「通知位置」，位于「主题设置」与「关于本软件」之间。
- **三种停靠方式**：
  - **顶部**：提示条固定在状态栏下方、页面顶部居中，不响应拖动。
  - **底部**：提示条固定在页面底部居中，位于内容区与底部导航栏之间，不遮挡导航按钮。
  - **自由拖动**：按住提示条即可上下左右移动；接近状态栏、屏幕左右边缘或底部安全区域时自动限位，避免文字被裁掉。
- **位置记忆**：自由拖动位置按可用移动范围的比例保存，切换页面、重启应用或横竖屏变化后仍落在相近位置。
- **预览与重置**：设置页提供「预览提示条」，以较长停留时间显示当前提示条，便于拖动确认是否遮挡按钮；「重置位置」将自由拖动位置恢复为顶部居中，不改变当前停靠方式。
- **默认行为**：升级后默认进入自由拖动模式，初始位置仍为顶部居中，不主动改变原有提示位置。
- **设置生效**：切换停靠方式立即生效并写入本机配置；顶部、底部模式不接受拖动。
- **版本号**：`versionCode 3` / `versionName 0.0.003`。

## 验证情况

- Kotlin 编译、`:app:assembleDebug`、`:app:assembleRelease` 均通过。
- 单元测试与 Paparazzi 截图测试共 35 项，全部通过。
- 在 Xiaomi 15（澎湃 / Android 15 / LSPosed 2.1.0）实测：
  - 「更多 → 通知位置」入口与页面正常打开，默认选中「自由拖动」。
  - 顶部模式提示条位于状态栏下方；底部模式位于底部导航栏上方，不遮挡导航按钮。
  - 自由拖动模式下将提示条从顶部拖至页面下方，松手后位置写入 `SharedPreferences`，重启应用后模式与位置均保持。

## 安装步骤

1. 设备已取得 root，并已安装 LSPosed（Zygisk 或 Riru 均可）。请将本模块作用域设为「系统界面」，随后重启系统界面。
2. 安装 `apptimer-lsposed-v0.0.003.apk`。同签名版本可直接覆盖升级；签名不同的旧包须先卸载。
3. 打开应用，进入「更多 → 通知位置」，选择顶部、底部或自由拖动；自由拖动模式下可先点「预览提示条」，再按住提示条移动到合适位置。

## 使用前须知

- 提示条位置仅影响本应用内的全局短提示，不改变计划执行、解锁、锁屏与权限逻辑。
- 顶部、底部为固定停靠，拖动无效；需要移动时请先切回「自由拖动」。
- 自由拖动位置以屏幕比例保存，不同分辨率或分屏尺寸下会落在相近的相对位置，而非完全相同的像素坐标。
- 通知位置配置目前仅保存在本机，不随「配置备份」导出或导入。
- 本版本主要在 Xiaomi 15（澎湃 / Android 15 / LSPosed 2.1.0）验证，其他机型请自行测试。
